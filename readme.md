Una selección personal de fondos de pantalla para darle estilo al escritorio.

## Contenido

La colección puede incluir paisajes, ilustraciones, fotografías y otros diseños. La mayoría de las imágenes tiene una resolución de 1920 × 1080 píxeles; algunas pueden tener dimensiones diferentes.

## Uso

Explora las imágenes y selecciona la que quieras usar como fondo de pantalla. Si una imagen se comparte o se reutiliza, respeta la licencia y los derechos de autor correspondientes; cuando sea posible, consulta la fuente original.

## Fuentes habituales

Las fuentes principales de la colección son:

- **Wallhaven (fuente principal):** [wallhaven.cc](https://wallhaven.cc/)
- [WallpapersCraft](https://wallpaperscraft.com/)
- [Pexels — wallpapers para escritorio](https://www.pexels.com/search/desktop%20wallpaper/)

> Colección personal: el contenido puede cambiar a medida que agregue, quite o reorganice wallpapers.
